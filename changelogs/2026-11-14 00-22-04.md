# Phase 2 first pad native and interface slice

## Changes

- Added a pinned React, TypeScript and Vite workspace. Its production JavaScript and CSS are embedded in the plugin and served by JUCE's local WebView resource provider.
- Added a 16-pad prototype interface with pad 1 wired to native sample selection, audition, snapshot reporting and master gain.
- Added worker-thread WAV, AIFF and FLAC decoding, immutable sample playback on MIDI note 36 with sample-offset scheduling and velocity, and bounded import validation.
- Added versioned native bridge commands and a smoothed, host-authoritative master gain parameter with automation gestures.
- Added host state version 2 with embedded decoded sample data and Phase 1 state compatibility.
- Added engine and full-processor recall tests, updated CI and build instructions, and documented the offline WebView2 runtime plan.
- Linked the local repository to the existing madisonmachine/hyperreal remote and developed this work on a Phase 2 feature branch.

## Affected areas

apps/plugin, packages/engine, packages/ui, tests, docs, CMake, CI, and repository configuration.

## Checks

- npm ci, TypeScript check, and Vite production build passed.
- Debug and Release VST3 and standalone builds passed.
- Debug and Release CTest passed both engine and full-processor state tests. The latter removed the original WAV before restoring playback.
- pluginval level 5 passed the Debug VST3 with editor tests and the Release VST3 headlessly.
- The developer machine has WebView2 Runtime 157.0.4341.46 installed.

## Known limitations

- Only pad 1 plays audio; overlap, gate mode, polyphony, choke and the complete 16-pad engine follow in Phase 3.
- Windows visual inspection was unavailable because the computer-use helper failed to initialize. Editor creation and close passed pluginval.
- Cubase Pro 15 recall and a clean offline installation have not been tested.
- The madisonmachine GitHub connection lacks push rights, so CI has not run remotely.
