# Phase 3 note behavior and host controls

14 November 2026

Changes: added per-pad one-shot/gate mode, choke groups 0 to 4 and audible pad level control. Gate note-off, choke triggers and MIDI all-notes-off use 5 ms release fades. The editor exposes the new controls for the selected pad and its height accommodates them. Host parameter IDs are stable and appended after the original controls. HRP4 state persists them while accepting HRP3, HRP2 and Phase 1 state.

Checks: React/TypeScript build, Release VST3/standalone build, engine/processor smoke tests and pluginval strictness 5 passed, including editor creation and automation. The smoke tests cover gate release, one-shot note-off, choke fade, all-notes-off, pad level, host command validation, saved-state recall and older-state migration.

Still open: manual Cubase Pro 15 checks of v0.3.0; drag-and-drop, pad operations, mute/solo, velocity response, configurable polyphony, click-free voice stealing, MIDI-channel-aware repeated-note ownership, transport reset and performance stress. The Phase 2 disconnected clean-Windows install remains a release gate.
