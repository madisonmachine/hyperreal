# Phase 1 initial codebase and build pipeline

## Changes

- Initialized the HYPERREAL monorepo on main and retained the three source briefs.
- Added a C++20 JUCE 9.0.5 silent instrument shell with VST3 and standalone targets, one stereo output, MIDI input, 16 stable pad-level parameter IDs, master gain ID, and versioned host state.
- Pinned JUCE to its commit and documented the CMake, MSVC, and WebView2 SDK prerequisites.
- Added architecture decisions, draft pad/kit/project-state schemas, a phase-to-requirement checklist, build instructions, and a Windows CI build with pluginval smoke validation.
- Created the requested package, asset, test, packaging, and changelog directories.

## Affected areas

Repository configuration, apps/plugin, docs, schemas, packages, assets, tests, packaging, and .github/workflows.

## Checks

- CMake configure passed with Visual Studio 2022 x64 and JUCE WebView2 integration discovered.
- Debug and Release VST3 and standalone builds passed.
- Headless pluginval v1.0.4 strictness level 5 passed for both Debug and Release VST3 builds, including plugin loading, state, automation, audio processing, and bus checks.
- CMake preset and JSON Schemas parsed; build output is ignored by Git.

## Known limitations

- The shell is silent and uses a temporary generic editor. Sample playback and the local React interface are later phases.
- The CI workflow has not run on GitHub because the madisonmachine repository/account is not yet connected.
- Cubase Pro 15 loading has not yet been checked.
- JUCE commercial versus AGPL licensing and offline WebView2 runtime packaging must be settled before distribution.
