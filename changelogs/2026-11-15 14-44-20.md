# Start Phase 5 amplitude shaping

Created the Phase 5 branch and added per-pad amplitude ADSR to native voices. The new host parameters are exposed in the embedded editor with a schematic graph, copied with pad settings, and saved in `HRP8` state. Older `HRP7` sessions migrate to default ADSR values. The project and UI development version is 0.5.0.

Checks: React/TypeScript build, Release VST3 build, engine and processor CTest suites, and pluginval strictness 5 with editor checks passed. The active-ADSR dense-trigger run averaged 0.140 ms per 128-frame block with steady private bytes during that section. Filter envelope, filters, LFO, full-chain validation and combined Phase 4/5 Cubase checks remain open. The Phase 5 bundle is built but not installed.
