# Phase 3 voice control and stress checks

14 November 2026

Changes: interrupted voices now move into a bounded 5 ms fade-tail pool. Gated note-off matches pad and MIDI channel. Each pad has a host-automatable voice limit of 1 to 4 and soft, linear or hard velocity response. One voice provides mono retrigger. A playing-to-stopped host playhead transition requests a 5 ms release of active voices. HRP6 saves the new controls and reads HRP5 and older states. A native file-drop target accepts one WAV, AIFF or FLAC file for the selected pad; routing through the embedded WebView still needs a Cubase check. Copy/paste/swap/clear includes the new per-pad controls.

Checks: TypeScript/Vite production build, Release VST3 and standalone build, engine and processor state tests, and pluginval strictness 5 passed. Engine tests cover steal tails, mono retrigger, velocity curves, channel-aware note-off, same-time choke ordering and transport-stop release. A closed-editor benchmark processed 1.6 million triggers in 100,000 blocks of 128 frames at 44.1 kHz in 5.90 seconds, averaging 0.059 ms per block with a 0.365 ms worst observed block. Private bytes remained at 2,543,616 through that run. These measurements are local and synthetic.

Still open: Cubase Pro 15 validation of v0.3.0, including editor controls, native file-drop routing and transport stop; per-pad drop targeting, tail-pool saturation behavior and long-session host memory/performance checks. The Phase 2 disconnected clean-Windows installation remains a release gate.
