# Fit all shaping controls without tab scrolling

Resized the rotary controls and narrowed the waveform and envelope preview areas. Waveform frame knobs now sit beside the shorter trace, with zoom, tuning, reverse and semitone snap below. The tabs size to their contents without an inner scrollbar. Removed the sampler subtitle and the always-visible source rate, duration and successful-edit message from the main display; loading and error feedback remain.

Checks: TypeScript/Vite production build, Release VST3 build, both native suites and pluginval strictness 5 with editor checks passed. Headless visual checks used an empty-pad editor and a loaded-sample fixture; the latter measured 263 px for Waveform and 209 px for Amp, Filter and LFO, with each panel's scroll height equal to its client height. The previous installed bundle was backed up, and the compact VST3 was installed while Cubase was closed. Its binary SHA-256 matches the Release build (`317D2E51E037A8AF109F39A4B2AC1E967C01D5F8078887BD93399D5B33B4A332`). Cubase interaction remains to be checked.
