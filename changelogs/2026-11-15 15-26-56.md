# Add per-voice LFO modulation

Implemented per-voice pitch and filter-cutoff LFO destinations with sine, triangle, square and saw shapes, 0.05–20 Hz rate, 0–24 semitone depth and reset/free-running phase behavior. Added five host parameters per pad, native bridge validation, an editor waveform preview and controls, pad-operation transfer, and `HR10` state with `HRP9` migration. The engine starts reset-phase voices at zero and advances a shared per-pad free-running clock even between notes.

Checks: React/TypeScript build, Release VST3 build, both native suites and pluginval strictness 5 with editor checks passed. Rendered-audio regressions cover pitch phase behavior and cutoff modulation. State checks cover invalid commands, saved-state recall, migration and pad operations. A synthetic full-chain run processed 1.6 million triggers in 100,000 blocks of 128 frames at 44.1 kHz in 59.69 seconds (0.597 ms average, 1.589 ms worst observed block), with private bytes decreasing from 4,186,112 to 4,091,904 during dense triggering. Host automation ergonomics, extended stability checks and combined Phase 4/5 Cubase checks remain open. The development build has not been installed for Cubase.
