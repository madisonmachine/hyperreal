# Phase 3 specification gap closure

14 November 2026

Added per-pad MIDI note-on counters to native snapshots and separate MIDI and click-audition flashes in the editor. One-shot playback now fades across the final 5 ms of source audio, ending at zero. When the 64 fade-tail slots are full, a selected old voice releases in place and the new trigger is dropped, so no tail is cut off abruptly. Added a test-only worker pause to verify that cancelling an in-flight decode preserves the current sample.

The TypeScript/Vite UI build, Release VST3/standalone build, both native smoke tests and pluginval strictness 5 passed on the final build. A 100,000-block dense-trigger benchmark averaged 0.067 ms per 128-frame block with 0.384 ms worst observed block; private bytes stayed level after warmup. The matching Release VST3 was installed in the per-user location while Cubase was closed. Cubase retesting of the revised visual feedback and sample ending remains open; sustained editor-open use and clean offline installation remain deferred.
