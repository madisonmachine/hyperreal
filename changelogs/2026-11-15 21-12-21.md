# Put shaping controls in display tabs

Replaced the four expandable Waveform, Amp Envelope, Filter and LFO sections with tabs inside the main display. Added a shared rotary control for waveform frame edits, tuning, zoom/view, amplitude ADSR, filter settings and envelope, and LFO settings. Knobs show their values, support pointer dragging with Shift for fine movement, and offer keyboard adjustment. Master Gain is now a vertical physical-style fader to the right of the 16 pads. Existing native parameter IDs, state format and DSP behavior are unchanged.

Checks: TypeScript/Vite production build, Release VST3 build, both native suites and pluginval strictness 5 with editor checks passed. Headless editor previews were reviewed at a 900 by 940 viewport, including a test fixture for the rotary panels. Cubase was open during this work, so the installed VST3 was left in place; the new bundle still needs installation and host interaction checks.
