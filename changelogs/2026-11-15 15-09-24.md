# Add per-voice filters and filter envelope

Implemented low-pass, high-pass and band-pass state-variable filtering for each voice, with an Off bypass, cutoff, resonance and bipolar filter-envelope depth. The independent filter ADSR uses the established one-shot and gated release rules. Per-voice stereo integrators preserve overlapping-note independence; cutoff, Q and depth move active voices through smoothed coefficient updates. Added host parameters, a custom filter panel, pad-operation transfer and `HRP9` state with `HRP8` migration.

Checks: React/TypeScript build, Release VST3 build, both native test suites and pluginval strictness 5 with editor checks passed. Audio regressions cover mode response, positive and negative envelope depth, attack, overlapping voices and maximum-resonance finite output. A synthetic run with both envelopes and low-pass filtering processed 1.6 million triggers in 100,000 blocks of 128 frames at 44.1 kHz in 44.55 seconds (0.445 ms average, 2.120 ms worst observed block). Private bytes decreased from 4,239,360 to 4,141,056 during that section. These measurements are local and closed-editor. LFO, full-chain validation and the combined Phase 4/5 Cubase checks remain open; the Phase 5 development build is not installed.
