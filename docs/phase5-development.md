# Phase 5 shaping filters and modulation

Development began 15 November 2026 on `phase5-shaping-filters-modulation`, based on the Phase 4 branch. Local implementation and native checks have progressed through the shaping controls; Phase 5 is not signed off. Phase 4 Cubase checks remain deferred to the combined host pass at the end of Phase 5.

## Implemented

- Added a per-voice, per-pad linear amplitude ADSR. Attack and decay ramp to sustain. A gate note-off releases from the current level. A one-shot with positive release begins its release near the edited sample end; a release longer than the remaining sample is clamped to that boundary. Zero-valued defaults preserve the earlier sound and 5 ms gated safety fade. Choke, mute, steal and transport-stop fades remain separate.
- Exposed 64 stable per-pad host parameters for amplitude attack, decay, sustain and release, with validation and host change gestures. The embedded editor has keyboard-operable range controls, numerical values and a schematic envelope graph. Host snapshots supply its values.
- Added the amplitude parameters to pad copy, paste, swap and clear. `HRP8` saves them, while `HRP7` and earlier states migrate to defaults.
- Added per-voice stereo state-variable filters with Off, low-pass, high-pass and band-pass modes. Cutoff is capped for the host rate, Q is limited to 0.5–10, and bipolar filter-envelope depth spans ±48 semitones. A separate filter ADSR controls that depth. Cutoff, Q and depth update active voices with smoothed coefficients; mode and envelope settings take effect on new voices. Filter state stays with each voice, including overlapping and stolen voices.
- Added host parameters, a filter panel and an independent envelope graph. `HRP9` persists filter settings and reads `HRP8` sessions with filter defaults. Pad copy, paste, swap and clear include the filter settings.
- Added per-voice LFO modulation of pitch or filter cutoff, with sine, triangle, square and saw shapes; 0.05–20 Hz rate; 0–24 semitone depth; and reset or free-running phase. Reset starts at phase zero on each voice; free-running phase continues between notes and resets when audio preparation restarts. Destination, shape and phase mode are captured at note onset. Rate and depth read live host values. The editor shows host-backed controls and a waveform preview. `HR10` state saves LFO settings and reads `HRP9` sessions with defaults. Pad copy, paste, swap and clear include LFO settings.
- Formatted Phase 5 host parameter values and units for seconds, hertz, Q and semitones, while retaining their parameter IDs, ranges and normalization. The editor polls native parameter snapshots with one read in flight. Amplitude, filter and LFO controls now share a bounded write queue: one native command is in flight per shaping panel, slider events for the same field collapse to the latest value, and commands are spaced by at least 16 ms. A pending local value is displayed immediately; a matching native snapshot confirms it, while failed commands restore the native value.
- Moved Waveform, Amp Envelope, Filter and LFO into keyboard-navigable tabs inside the main display. Replaced their continuous value sliders and waveform frame/tuning entry boxes with rotary controls that retain numeric readouts, pointer dragging, fine Shift-dragging and keyboard adjustment. Discrete filter and LFO choices also use rotary detents. Moved Master Gain to a physical-style vertical fader beside the 16 pads. Native parameter IDs and the live waveform edit path are unchanged.
- Compacted the tab content so it needs no internal scrolling: reduced rotary sizes, narrowed waveform and envelope preview areas, placed waveform frame knobs beside the trace and view/tuning controls below it. Removed the sampler subtitle and the always-visible source rate, duration and successful-edit message from the main display. Import and error messages remain visible when relevant.
- Embedded the supplied Honk font for the HYPERREAL logo and Pixelify Sans for the selected pad/MIDI label, sample title and status. Added an eight-segment post-gain output meter alongside the Master Gain fader: four green, two amber and two red LEDs, with a short clip hold. Rotary value arcs now stop at each knob's indicator.
- Changed the master meter to separate left and right rows of eight smaller LEDs beneath the fader. Each row reads its own post-gain output channel and clip hold; the rows are labelled L and R.

## Checked locally

The React/TypeScript production build, Release VST3 build, both native CTest suites and pluginval strictness 5 with editor checks pass. Engine regressions cover ADSR stages, gated release and a one-shot release longer than the remaining sample. Processor tests cover invalid commands, saved-state recall, pad operations and migration from `HRP7`. A synthetic run with a non-default ADSR on every pad processed 1.6 million triggers in 100,000 blocks of 128 frames at 44.1 kHz: 0.140 ms average and 1.134 ms worst observed block, with private bytes steady at 4,198,400 during that dense-trigger section. This is a local closed-editor benchmark, not a host guarantee.

The filter slice also passes the React/TypeScript build, Release VST3 build, both CTest suites and pluginval strictness 5. Rendered-audio checks cover filter-mode DC response, positive and negative envelope depth, filter-envelope attack, independent overlapping voices, and finite output at high Q. Processor tests cover filter command ranges, `HRP9` recall, `HRP8` migration and pad operations. A synthetic run with both envelopes and low-pass filtering processed 1.6 million triggers in 100,000 blocks of 128 frames at 44.1 kHz: 0.445 ms average and 2.120 ms worst observed block, with private bytes decreasing during that dense-trigger section. This is a local closed-editor result, not a host guarantee.

The LFO slice passes the React/TypeScript build, Release VST3 build, both CTest suites and pluginval strictness 5 with editor checks. Engine audio regressions cover reset and free-running pitch phase and cutoff modulation. Processor checks cover invalid LFO commands, `HR10` recall, `HRP9` migration and pad operations. The synthetic full shaping chain benchmark processed 1.6 million triggers in 100,000 blocks of 128 frames at 44.1 kHz: 0.597 ms average and 1.589 ms worst observed block, with private bytes falling from 4,186,112 to 4,091,904 during dense triggering. This is a local closed-editor result, not a host guarantee.

The automation presentation slice passes the React/TypeScript build, Release VST3 build, both native suites and pluginval strictness 5 with editor checks. The processor test checks host text and units for amplitude attack, filter cutoff and depth, and LFO rate and depth. It also changes filter cutoff and LFO rate through the host parameter API and confirms those values reach the editor snapshot. The control queue is verified by build and code review; its drag behavior and visible host-originated automation still require the combined Cubase pass. A full-chain stress matrix exercises three host rates (1, 44.1 and 96 kHz), all three filter modes, all four LFO shapes, pitch and cutoff destinations, 20 Hz modulation, maximum resonance, alternating cutoff and envelope depth, and repeated triggers. Output stayed finite and bounded in every case. A ten-second silent tail returned exactly to silence in the local test. The tabbed/rotary editor passes the production UI build, Release VST3 build, both native suites and pluginval strictness 5. Headless screenshots confirm the pad grid and master fader fit together, and the knobs and readouts are legible. A loaded-sample fixture measured tab content heights of 263 px for Waveform and 209 px for each other tab at a 900 px viewport, with no internal overflow. Cubase interaction remains to be checked.

The font, meter and rotary arc update passes the production UI build, Release VST3 build, both native suites and pluginval strictness 5. A headless screenshot confirms that both embedded fonts render and that the stereo meter fits beneath the fader. Processor regressions use left-only and right-only stereo fixtures, trigger overlapping notes past 0 dBFS, and check that only the active channel clips. The left meter and hold also decay on silence. The knob arc now uses the value-dependent SVG dash length rather than the former fixed CSS dash. Cubase visual and audio behavior remains to be checked in the combined host pass.
